# Kampung Indonesia: Global Reach

Build a premium, production-quality website for Kampung Indonesia based strictly on the attached PRD and Airbnb Design System Analysis.

Use the PRD as the primary source of truth for:

information architecture

content hierarchy

page structure

UX requirements

responsive behavior

audience priorities

brand positioning

Use the Airbnb Design System Analysis only as a visual design reference, not as something to copy literally.

The website structure must be complete. Do not generate only the hero and content sections.

REQUIRED GLOBAL HEADER

Create a visible, polished, responsive navigation bar at the top of the website.

Desktop header must include:

Kampung Indonesia logo on the left

About

What We Do

Countries

Partnerships

Impact

Insights

Global / Country selector

Contact

The header should be sticky while scrolling.

At the top of the page it can feel visually light, but after scrolling it should use a clean white background with a subtle border.

On mobile, collapse the navigation into a well-designed menu or sheet while keeping the logo clearly visible.

REQUIRED GLOBAL FOOTER

The homepage must end with a complete institutional footer.

Include these footer groups:

Platform

About

What We Do

Countries

Impact

Work With Us

Partnerships

Programs

Contact

Knowledge

Insights

Research

Stories

Country Platforms

Thailand

Follow

LinkedIn

Instagram

Also include a bottom legal row with:

Kampung Indonesia copyright

Privacy

Terms

English

Institutional contact information placeholder

Do not omit the footer.

VISUAL DIRECTION

The visual direction should feel:

premium

warm

international

institutional

human-centered

photography-led

clean and modern

Use red as the primary brand accent, while white and neutral colors should dominate the interface.

Keep red usage restrained and intentional.

Prioritize:

generous whitespace

strong editorial photography

soft rounded geometry

excellent typography hierarchy

subtle elevation

polished micro-interactions

strong responsive design

accessibility

high visual quality

Avoid:

generic SaaS aesthetics

glassmorphism

excessive gradients

fake statistics

fake programs

fake testimonials

excessive icon cards

overly corporate layouts

incomplete website structure

FIRST GENERATION SCOPE

For the first generation, create a fully structured and polished homepage containing:

Global Header with complete navigation

Hero

Who We Are

The Connections We Build

What We Do

How We Work

Country Platforms

Kampung Indonesia Thailand preview

Collaborative Ecosystem

Strategic Development Partners

Impact Framework

Insights

Closing Invitation

Complete Global Footer

Also build:

responsive mobile navigation

responsive homepage layout

reusable homepage components

Do not sacrifice structural completeness.

The homepage should feel like a finished public institutional website, not a landing-page concept or partial prototype.

The final result should establish a distinct Kampung Indonesia design system, inspired by Airbnb’s clarity, warmth, whitespace, image-first storytelling, and interaction quality, while remaining original and appropriate for an International Education & Community Development Platform.

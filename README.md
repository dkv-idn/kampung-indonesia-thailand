# Kampung Indonesia - Thailand Platform

Welcome to the Kampung Indonesia Thailand Platform repository. This project is a premium, production-quality web application built to serve as the digital presence for Kampung Indonesia's initiatives in Thailand.

## About The Project

Kampung Indonesia is an International Education & Community Development Platform. This platform specifically highlights the collaborative ecosystem, strategic development partnerships, and impact frameworks active in Thailand. The design language is clean, modern, and human-centered, prioritizing high-quality editorial photography and strong typography to tell compelling stories.

This application is built with modern web technologies to ensure a fast, responsive, and accessible user experience across all devices.

## Tech Stack

*   **Framework:** [React 19](https://react.dev/)
*   **Routing & SSR:** [TanStack Start](https://tanstack.com/start/latest) with [TanStack Router](https://tanstack.com/router/latest)
*   **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
*   **UI Components:** [Radix UI](https://www.radix-ui.com/) primitives
*   **Build Tool:** [Vite](https://vitejs.dev/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)

## Features

*   **Global Navigation:** Responsive header with sticky behavior.
*   **Dynamic Content:** Sections for "Who We Are", "What We Do", and "Country Platforms".
*   **Premium Design:** Custom styling system inspired by modern institutional platforms.
*   **Responsive Layout:** Fully optimized for mobile, tablet, and desktop viewports.
*   **Accessibility First:** Built using accessible primitives from Radix UI.

## Getting Started

### Prerequisites

You need Node.js and npm installed. We recommend using [nvm](https://github.com/nvm-sh/nvm#installing-and-updating) to manage your Node versions.

### Installation

1.  Clone the repository:
    ```bash
    git clone <this-repository-url>
    cd <repository-name>
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

The application will be available at `http://localhost:3000` (or another port if 3000 is taken).

## Scripts

*   `npm run dev`: Starts the Vite development server.
*   `npm run build`: Builds the application for production.
*   `npm run preview`: Previews the production build locally.
*   `npm run lint`: Runs ESLint to check for code issues.
*   `npm run format`: Runs Prettier to format the codebase.
